# Advanced-python-simple-projects
## Advanced Python Mini Projects

This repository contains a collection of small Python projects that use slightly advanced concepts like regular expressions, GUI (Graphical User Interface), and logical operations. These programs are built using basic Python libraries and are helpful for learning how to apply Python in real situations.

Each file in this repository shows a different idea — some include simple calculations, some check user inputs, and some use a graphical interface for a better user experience. These projects are kept simple and easy to understand, so anyone with basic Python knowledge can explore them and learn more.
### How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal or command prompt in the project folder.
4. Run the file using:

```bash
python filename.py
```

Replace `filename.py` with the name of the file you want to run.
###Features

- Uses only built-in Python modules (no need to install anything extra).
- Easy-to-read code, suitable for beginners.
- Great for learning Python beyond the basics.
